## Оформление

- Тёмный сине-фиолетовый фон с мягкими световыми акцентами; не использовать Material You, динамические системные цвета и стандартные Android-компоненты Material.
- Округлые вкладки с иконками; активная «Играть» — лавандовая с тёмным текстом.
- Главная панель содержит **настоящую Minecraft-панораму**, а не геометрические прямоугольники. Изображение подлежит подготовке как отдельный локальный ресурс, оптимизации по памяти и юридической проверке.
- Поверх панорамы слева — затемнение, заголовок, версия и профиль, три шага установки и прогресс реальной загрузки.
- Карточки и кнопки имеют реальные touch hit targets, доступные состояния нажатия и читаемый русский текст.

## Действия без заглушек

- «Играть» — существующий запуск установленной игры.
- «Моды» — онлайн-поиск в реальном реестре совместимых модов; пагинация, установка и проверка совместимости. Не показывать неработающие проекты только ради большого числа результатов.
- «Ресурсы» и «Шейдеры» — реальные сетевые источники, поиск, страницы результатов, установка, состояние загрузки.
- «Установлено» — реально установленные файлы и управление ими.
- «Настройки» и «Дополнительные опции» — одна функциональная страница.
- «Офлайн / Войти» — существующая авторизация, без фиктивного входа.
- «Выбор профиля» — существующие профили и сохранение выбора.
- «Скачать Minecraft» — фактическая установка с прогрессом, «Играть» после завершения.
- GitHub — действительная ссылка на этот репозиторий.

## Обязательные проверки до выпуска

1. Сборка ARM64 и отсутствие Rust/Java ошибок.
2. Проверка установки поверх **того же подписанного** APK, без удаления данных.
3. Проверка кириллицы во всех разделах, включая мобильное управление, без английских заглушек.
4. Работа кнопок, авторизации, установки и сетевых каталогов на устройстве.
5. Измерение RSS/памяти и времени кадров в одинаковом мире до/после; не обещать прирост без результатов.
6. Сравнение экранов на реальном устройстве с эталоном и исправление расхождений.
7. Только после этих шагов — GitHub Actions и подписанный Release.

Движок игры, сохранения миров и существующие раскладки не менять при переделке лаунчера.
