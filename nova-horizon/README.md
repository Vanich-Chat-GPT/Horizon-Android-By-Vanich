# NOVA HORIZON

Самостоятельный Android-проект для исследования и разработки легального запуска Minecraft Java Edition на ARM64.

> Текущий статус: ранняя независимая разработка. Приложение содержит Kotlin/Compose оболочку, Rust JNI-модуль, диагностику устройства и EGL/OpenGL ES, официальный каталог Mojang, выбор версии, проверку метаданных, авторизацию Microsoft и подсистему загрузки игровых файлов. Проверка CI подтверждает сборку ARM64 debug APK, но не запуск Minecraft на физическом устройстве. Это ещё не полноценный игровой клиент.

## Принципы

- Исходники этого каталога написаны отдельно. Код, скрипты и бинарные файлы Horizon, Starling, PojavLauncher и других портов не используются.
- Не включаем игровые файлы, библиотеки или ресурсы Minecraft в APK.
- Используем только законно полученные игровые файлы и официально разрешённую авторизацию.
- Не подделываем токены и не обходим лицензионные проверки.
- Не называем тестовые сцены Minecraft и не показываем фиктивные статусы установки.
- Не обещаем FPS или совместимость без измерений на реальном устройстве.
- Основной ABI на старте: arm64-v8a.

## Структура

- app/ — Kotlin + Jetpack Compose Android application.
- core/ — независимое Rust-ядро, JNI bridge, валидатор официального version manifest, модель загрузки и приоритетный планировщик задач.
- docs/ — архитектура, безопасность, этапы и тестовая матрица.
- THIRD_PARTY_NOTICES.md — реестр используемых инструментов и зависимостей.

## Сборка

Требуются JDK 17, Android SDK API 36, Android NDK r30, Gradle 8.13 и Rust stable.

Из корня репозитория CI выполняет:

- cargo fmt --manifest-path nova-horizon/core/Cargo.toml -- --check
- cargo test --manifest-path nova-horizon/core/Cargo.toml
- cargo clippy --manifest-path nova-horizon/core/Cargo.toml --all-targets -- -D warnings
- cargo ndk -t arm64-v8a -o ../app/src/main/jniLibs build --release из nova-horizon/core
- gradle assembleDebug из nova-horizon/

Debug APK не является стабильным подписанным релизом. Успешная CI-сборка доказывает компиляцию и проверку ABI, но не физическое тестирование игры.

## Текущая функциональность

- Реальное чтение публичного version_manifest_v2.json по HTTPS с ограничением размера и строгой проверкой хоста/перенаправлений.
- Проверка структуры, ID, дубликатов, SHA-1 и официальных URL внутри Rust Core.
- Полный список официальных версий, поиск и выбор версии в Android UI.
- Получение метаданных выбранной версии с проверкой SHA-1 из официального каталога.
- Консервативный ARM64-план: client JAR, asset index и только те обычные JAR-библиотеки, правила Mojang для которых удалось безопасно разрешить. Desktop native classifiers не маскируются под Android.
- Расширение asset index в дедуплицированный список объектов с проверкой SHA-1, размеров и официальных URL.
- Пакетная загрузка ресурсов с ограниченной параллельностью, возобновлением отдельных файлов, проверкой целостности и системными уведомлениями о прогрессе/скорости.
- Материализация legacy-структуры ресурсов через hard links, если файловая система поддерживает их, иначе через проверяемое копирование.
- Проверка свободного места перед загрузкой; это резерв дискового пространства, а не ограничение RAM.
- OfficialArtifactDownloader реализует HTTPS-загрузку с allowlist хостов, проверкой размера и SHA-1, Range/If-Range с сильным ETag, fsync и атомарным продвижением файла.
- Android 14+ использует User-Initiated Data Transfer Job; Android 8–13 — WorkManager.
- Реальное определение OpenGL ES renderer/vendor/version/extensions из созданного EGL-контекста.
- Диагностика ABI, CPU core count, доступной/общей RAM и thermal status через Android API.
- Rust queue дедуплицирует задания по координатам, удерживает актуальные поколения и очищает устаревшие записи.
- Rust frame-time sample window с unit tests.

## Что ещё не готово

Скачивание проверенных JAR-файлов и ресурсов ещё не означает готовую установку или возможность запуска. Не завершены совместимый ARM64 Java SE runtime, Android/Bionic native bridge, LWJGL/GLFW графический слой, звук, ввод, полная обработка native classifiers, конфигурация JVM/game arguments, запуск мира и восстановление после pause/resume. Поэтому кнопка реального запуска не активируется.

## Важное архитектурное ограничение

Minecraft Java Edition использует JVM, LWJGL и графические/системные API. Android ART не заменяет Java SE runtime для desktop JAR. Поддержка игры требует отдельной проверки ARM64 JVM, игровых native-библиотек, оконно-графического слоя, ввода, аудио и сетевого окружения.
