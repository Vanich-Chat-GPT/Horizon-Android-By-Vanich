# NOVA HORIZON

**NOVA HORIZON 3** — неофициальная Android-сборка Horizon, Minecraft: Java Edition 26.3, переписанного на Rust. Игровой цикл и рендерер нативные; это не запуск обычного Java-клиента через Pojav/Amethyst.

## Игровая основа и Android-порт

- Horizon: [horizon-rust/horizon](https://github.com/horizon-rust/horizon) — Rust-реализация Minecraft Java 26.3.
- Android-порт и развитая мобильная оболочка: [scpao5/starling](https://github.com/scpao5/starling), продолжение Android-ветки Horizon.
- Закреплённый upstream commit: `50e0ef409738310524e18f77aa8ee6c4378987ed`.
- Vulkan/wgpu rendering, NativeActivity, Android audio/input bridge, экранные контролы и редактор раскладки.
- Android diagnostics: логи, сведения о завершении процесса, экспорт отчёта и CPU/GPU/frame profiling.
- Подготовка ресурсов из собственной копии Minecraft 26.3; игровые файлы Mojang в APK не входят.

## NOVA HORIZON identity

- Package ID: `dev.nova.horizon`
- App label: `NOVA HORIZON`
- Version: `3.0.0`
- ABI: `arm64-v8a`
- Build profile: Cargo `fast`
- APK: `NOVA-HORIZON-3.0.0-arm64-v8a.apk`

Android home screen оформлен по v3-референсу: верхняя навигация, боковая панель, выбор Minecraft 26.3, Play, быстрые карточки для диагностики/модов/ресурспаков/шейдеров и журнал. Файлы можно выбрать через системный picker; импорт передаётся движку Horizon. Графические настройки и игровые действия остаются внутри Rust-клиента.

Тестовая APK подписывается стабильным публичным тестовым ключом upstream, а не приватным production-ключом. Это сборка для установки и проверки, не финальная защищённая release-подпись.

## Запуск игры

Нужна собственная легально приобретённая копия Minecraft: Java Edition 26.3 и Microsoft-аккаунт, владеющий Java Edition, для загрузки официальных файлов Mojang. APK не включает клиент, сервер, текстуры, звуки или другие проприетарные игровые данные.

При первом запуске выполняются вход, загрузка Java 25 для подготовки ресурсов и подготовка файлов игры. Игровой цикл при этом остаётся Rust. Оставь приложение открытым до завершения подготовки. Фоновое уведомление показывает состояние задачи и измеренную скорость сети в MB/s.

## Производительность и совместимость

Android-порт требует ARM64, Android 8+ и Vulkan. Профиль `fast` включает оптимизированную компиляцию Rust. В игровом коде уже есть отдельные worker threads, обработка входящих chunk packets с бюджетом времени кадра и лимиты загрузки мешей. Android Diagnostics показывает frame time, CPU/GPU, память, температуру и очереди.

Мобильные настройки NOVA HORIZON выставляют потолок 90 FPS, сохраняют 100% разрешение рендера и обычные эффекты ближней картинки; на менее мощных уровнях снижаются дальность симуляции/отрисовки и детализация дальнего ландшафта. Искусственный лимит RAM не вводится. 90 FPS — целевая настройка, не обещание: реальный результат зависит от сцены, температуры и драйвера.

Целевое устройство — Redmi Pad SE 8.7 с MediaTek Helio G85, Mali-G52 MC2 и дисплеем до 90 Гц. Совместимость Vulkan и фактический FPS нужно проверить на самом планшете; характеристики дисплея не гарантируют 90 FPS в игре.

## Что ещё требует проверки на устройстве

- Установка и первый запуск на Redmi Pad SE 8.7.
- Вход Microsoft и получение официальных игровых файлов.
- Создание/загрузка мира, сохранение и повторный запуск.
- Сенсорное управление: статичный джойстик по умолчанию и плавающий режим.
- Импорт модов, ресурспаков и шейдеров поддерживаемых форматов.
- Звук, сворачивание/возврат, уведомление и скорость загрузки.
- Vulkan driver stability, frame pacing, нагрев, память и загрузка чанков.
- Обновление APK поверх предыдущей сборки и сохранение миров.

## Сборка

Workflow **NOVA HORIZON — Rust 26.3 Android ARM64** клонирует закреплённый upstream commit, применяет branding/JNI patch и интеграцию лаунчера, запускает Android unit/diagnostics tests, собирает оптимизированный ARM64 APK и проверяет package ID, native libraries, ресурсы, 16 KB alignment и подпись. Crash symbols загружаются отдельным CI artifact.
