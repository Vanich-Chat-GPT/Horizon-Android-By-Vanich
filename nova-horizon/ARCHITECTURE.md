# Архитектура NOVA HORIZON

## Границы системы

NOVA HORIZON разделяет Android-приложение, независимое нативное ядро и будущий игровой runtime. Rust Core не является реализацией Minecraft и не подменяет Java Virtual Machine.

### Android Application (Kotlin)

Отвечает за:
- жизненный цикл Android Activity;
- адаптивный UI;
- системные разрешения и уведомления;
- безопасную работу с хранилищем;
- интеграцию с Android DownloadManager/WorkManager после реализации загрузчика;
- сбор доступной информации об устройстве.

### Rust Core

Отвечает за вычислительно независимые подсистемы:
- сбор и агрегацию метрик frame-time;
- планирование фоновых задач;
- управление поколениями задач и отменой устаревшей работы;
- будущие CPU/RAM-профили и диагностику;
- JNI-контракт с Kotlin.

### Rendering / runtime boundary

До выбора и аудита JVM и графического пути игровой запуск заблокирован. Требуется доказать:
1. запуск совместимого Java runtime на Android ARM64;
2. загрузку только разрешённых нативных библиотек;
3. корректный EGL/OpenGL ES или Vulkan lifecycle;
4. интеграцию оконных и input API;
5. корректное поведение при pause/resume и потере поверхности;
6. работу с официально полученными файлами конкретной версии Minecraft.

Никакой backend не будет объявлен Vulkan-совместимым только по наличию Vulkan API на устройстве.

## Поток задач

Задачи фоновой обработки имеют:
- координаты/ключ области;
- расстояние до приоритетной точки;
- поколение актуальности;
- монотонный sequence number для стабильного порядка.

Очередь Rust на текущем этапе — универсальный планировщик тестовых задач. Она не читает мир Minecraft, не генерирует чанки и не строит игровые меши.

## Политика качества

- Не ограничивать RAM произвольным жёстким лимитом.
- Не ухудшать ближнюю графику без согласия пользователя.
- Любая оптимизация сопровождается тестом и сравнением.
- Реальные FPS, 1% low, frame-time и тепловая стабильность подтверждаются только на физическом Android-устройстве.
- Тестовые/эмуляторные результаты явно маркируются.
