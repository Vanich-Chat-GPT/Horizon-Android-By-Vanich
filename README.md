# ⛏️ HorizonCraft — Minecraft Java на Android

**HorizonCraft** — Android ARM64-приложение для запуска Minecraft Java Edition с сенсорным управлением, русскоязычным интерфейсом, игровыми профилями и настройками графики.

Проект ориентирован прежде всего на **Android 16 и устройства ARM64**, включая планшеты с ограниченным объёмом оперативной памяти. Работа на других версиях Android и с различными GPU-драйверами может отличаться.

## 🎮 Возможности

- **Minecraft Java Edition:** запуск игры на Android ARM64, офлайн-профили и предусмотренная приложением авторизация.
- **Русский язык:** локализация интерфейса лаунчера и русский язык Minecraft по умолчанию для нового профиля; сохранённый выбор языка пользователя не перезаписывается.
- **Управление:** настройка сенсорных кнопок непосредственно внутри Minecraft, сохранение раскладки по профилям.
- **Графика:** выбор профиля производительности, дистанции прорисовки и масштаба рендеринга.
- **Ресурсы:** установка и проверка файлов игры с отображением прогресса; предусмотрен Android-сервис фоновой установки с уведомлениями.
- **Моды, ресурспаки и шейдеры:** соответствующие разделы лаунчера, с учётом совместимости конкретного содержимого.

### Онлайн-каталоги модов и шейдеров

Во вкладке **«Моды»** доступен поиск по онлайн-каталогу Horizon с постраничной навигацией, а также импорт совместимых `.hmod` по HTTPS. Во вкладке **«Шейдеры»** доступны нативные пакеты Horizon и отдельный источник Modrinth. Каталог показывает результаты сервера, а не выдуманный список «всех существующих» модов. Наличие конкретного мода и совместимость шейдеров зависят от сервера каталога и версии игры.

## ⚡ Память и плавность игры

Android-профиль по умолчанию теперь ориентирован на планшеты с ограниченной RAM. На первом запуске новой версии профиль один раз мигрирует настройки; после этого изменения, которые пользователь делает вручную, не перезаписываются на каждом старте.

- Полноценная дальность чанков уменьшается максимум до 8, а симуляция — максимум до 6. Это снижает число одновременно резидентных чанков, палитр блоков, секций света и мешей; если установленное значение и так меньше, оно сохраняется.
- Для дальнего горизонта включается штатный LOD с уменьшенной детализацией (по умолчанию до 32 чанков). Ближние резидентные чанки сохраняют полноценную геометрию и освещение; дальний участок рисуется более крупными плитками.
- Лимит кадров по умолчанию не превышает 90 FPS; текущее значение VSync не отключается принудительно. На фактическую частоту влияют экран, нагрузка GPU/CPU и температура устройства.
- Для фоновой генерации на Android выбирается не более трёх воркеров по числу доступных CPU. Также включается отсечение сущностей, полностью скрытых непрозрачным рельефом.
- Планировщик генерации удерживает только ближайший необходимый пакет кандидатов вместо временного списка всех кандидатов. Готовые результаты извлекаются из очереди напрямую, без дополнительного большого вектора; новые ограничения на количество результатов за кадр не добавляются.
- Неиспользуемые секции и результаты не выбрасываются ради бенчмарка. Дальность полной детализации уменьшена намеренно; если нужен другой баланс дальности/плавности, графические настройки можно изменить вручную.

Эти изменения рассчитаны на снижение нагрузки и пиков памяти, но сами по себе не доказывают конкретный прирост FPS. CI проверяет компиляцию, целостность и подпись APK; для подтверждения среднего FPS, 1% low, frame-time и RAM необходим тест на реальном ARM64-устройстве в одном и том же мире и при одинаковой температуре.

## 📱 Установка и обновление

1. Скачайте APK из раздела **Releases**.
2. Для обновления поверх существующей установки должны совпадать **имя пакета и сертификат подписи**, а `versionCode` нового APK должен быть выше.
3. Для APK v1.1.1 и v1.2.0 использован совместимый сертификат. **У исходного v1.0.0 сертификат отличается**, поэтому прямое обновление с него Android отклонит.
4. Перед любым удалением старого приложения **сделайте резервную копию миров, профилей и настроек**: удаление приложения может удалить локальные данные.

В опубликованном v1.3.3-r61 используется пакет `dev.horizon.android` с `versionCode 33`. Следующая сборка с обновлённым оформлением получит `versionCode 34` и тот же сертификат для установки поверх неё. Совместимость обновления подтверждается только после проверки фактически собранного APK. Не следует удалять старую установку, пока не сохранены данные.
